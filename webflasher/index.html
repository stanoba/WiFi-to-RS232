🚀 Quick 4-Step Flashing Guide

  1. Connect ESP32: Plug your Wemos D1 Mini ESP32 (or compatible ESP32 board) into your computer's USB port.
  2. Click Flash Button: Click the gradient button above to open the browser Web Serial port selector.
  3. Select Serial Port: Choose your ESP32's COM / USB Serial port from the popup list.
  4. Install & Erase: Click Install (check Erase Device on initial installation) and wait ~35 seconds for completion.

🔄 Wireless OTA Firmware Binaries (Existing Installations)

If you already have the device running on your WiFi network, update wirelessly via the web interface:

Download Smart Monitor OTA (.bin) Download BMS Emulator OTA (.bin)
  1. Navigate to your device's web portal at http://<device-ip>/update.
  2. Select the downloaded .bin firmware file and click Update Firmware.
  3. ESP32 will write the image into its secondary OTA partition and reboot seamlessly.
